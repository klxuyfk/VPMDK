# Native AOTI on TITAN V

Validated on 2026-11-06 with Python 3.12.3, torch 2.12.0+cu126 and the four
cuEquivariance packages at 0.6.1. This experimental profile intentionally
replaces upstream's 0.12 pins. It uses the actual SM 7.0 native kernels.

- `export-report.json`: verified package/checkpoint hashes, bounds, ABI,
  runtime and target GPU, generated by `vpmdk-mace-soyo-export`.
- `export-check.log`: the actual compiled-versus-eager checks at export.
- `calculation-report.json`: VPMDK compiled/direct comparisons for 2, 4 and
  8 atoms, plus comparison with the original 0.12 `naive` reference.
- `OUTCAR.txt`, `OSZICAR.txt`, `CONTCAR.vasp`: actual AOTI CLI relaxation outputs.

All six AOTI integration tests passed, covering finite differences, static,
relaxation, MD, resident reuse and multiple atom counts. The package itself
is kept outside Git at
`/home/nei/.cache/vpmdk/mace-soyo/mace_soyo_mptraj-sm70-cueq061.pt2`.
Re-export in the matching environment if hardware, libraries or bounds change.
The standard 0.12 profile remains available independently.

and [environment instructions](../../../../docs/development/backend-environments.md#experimental-sm-70-library-replacement).
